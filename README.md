# Электронная Сеть - API и Админ-Панель

Этот проект представляет собой веб-приложение для управления сетью по продаже электроники, реализованное с использованием Django и Django REST Framework (DRF). Приложение включает в себя админ-панель для управления данными и API для взаимодействия с клиентами.

## Описание

Проект реализует иерархическую структуру из трех уровней:
- Завод
- Розничная сеть
- Индивидуальный предприниматель

Каждое звено сети ссылается на одного поставщика оборудования и имеет следующие характеристики:
- Название
- Контакты:
  - Email
  - Страна
  - Город
  - Улица
  - Номер дома
- Продукты:
  - Название
  - Модель
  - Дата выхода на рынок
- Поставщик (предыдущий по иерархии)
- Задолженность перед поставщиком
- Время создания (автоматически заполняется)

## Установка

### Предварительные требования

- Python 3.x
- Django 3.x или выше
- Django REST Framework

### Шаги по установке

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/DanielNegusto/electronics_network.git
    cd electronics_network
    ```
2. Создайте и активируйте виртуальное окружение:
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Windows используйте `venv\Scripts\activate`
    ```
3. Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
4. Создайте базу данных и примените миграции:
    ```bash
    python manage.py makemigrations
    python manage.py migrate
    ```
5. Запустите сервер разработки:
    ```bash
    python manage.py runserver
    ```
Теперь админ-панель доступна по адресу: http://127.0.0.1:8000/admin/, а API - по адресу: http://127.0.0.1:8000/api/.
